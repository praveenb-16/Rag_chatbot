2.3 Vector Database Architecture

The AI Nexus system employs a hybrid retrieval architecture using a vector database for semantic search combined with BM25 keyword search for precise term matching. The primary vector store is Pinecone, configured with 1536-dimensional embeddings generated via OpenAI's text-embedding-3-large model.

The retrieval pipeline follows these steps:

  1. Query embedding generation using the same model as the document embeddings
  2. Approximate nearest neighbor (ANN) search with cosine similarity
  3. BM25 keyword re-ranking for precision improvement
  4. Reciprocal Rank Fusion (RRF) for combining results
  5. Context window assembly with source attribution
Retrieved Chunk: The system uses a chunk size of 1024 tokens with 128-token overlap to ensure contextual continuity across document boundaries. Each chunk is stored with metadata including document ID, page number, section header, and creation timestamp.
